usage: mdview [-h] [--verify-resize-detection] [--test-input-feedback]
              [--reflow] [--reflow-mode {prose,all,none}] [--noreflow]
              [--verbose] [--stdin-timeout-in-seconds SECONDS]
              [--max-stdin-buffer-megabytes MEGABYTES] [--allow-huge] [--MIL]
              [--readability-first-tables] [--no-table-borders]
              [--no-cell-borders] [--automation-timeout SECONDS]
              [--automation-timeout-screenshot BASENAME]
              [--screen-dump-dir DIRECTORY] [--viewport-columns COLUMNS]
              [--viewport-rows ROWS] [--allow-insane-geometry]
              [--automation-json SOURCE] [--allow-huge-automation-scripts]
              [--redraw-check-digit] [-V]
              [paths ...]

Render Markdown or plain text in the terminal with integrated navigation.

positional arguments:
  paths                     Path(s) to Markdown or text files to view.
                            Required unless --verify-resize-detection or
                            --test-input-feedback is used, or stdin provides a
                            buffered document. (default: None)

options:
  -h, --help                show this help message and exit
  --verify-resize-detection
                            Guide a manual resize sequence, acknowledging
                            detected events and reporting pass/fail results.
                            (default: False)
  --test-input-feedback     Run a two-stage terminal input diagnostic that
                            compares plain stdin handling against the
                            prompt_toolkit viewer stack. (default: False)
  --reflow                  Enable reflow processing. If no explicit mode is
                            supplied, defaults to --reflow-mode prose.
                            (default: False)
  --reflow-mode {prose,all,none}
                            Select reflow policy mode explicitly. Applies even
                            without --reflow. (default: None)
  --noreflow                Disable reflow in all cases (equivalent to
                            --reflow-mode none). (default: False)
  --verbose                 Report key operational events, including document
                            switches in multi-document sessions. (default:
                            False)
  --stdin-timeout-in-seconds SECONDS
                            Stop waiting for additional stdin bytes after
                            SECONDS have elapsed with no further input.
                            (default: 2.0)
  --max-stdin-buffer-megabytes MEGABYTES
                            Refuse buffered stdin documents larger than
                            MEGABYTES unless the operator explicitly raises
                            the safety ceiling. (default: 16.0)
  --allow-huge              Allow file inputs up to 4 GiB instead of the
                            default 16 MiB ceiling. (default: False)
  --MIL, --mil              Enable Monkey-in-the-Loop telemetry: emit operator
                            action events and targeted troubleshooting
                            context. (default: False)
  --readability-first-tables
                            Always use readability-first table layout, even
                            when fit-first could fit the viewport. (default:
                            False)
  --no-table-borders        Suppress outer Markdown table borders and leave
                            whitespace gaps at the table edges. (default:
                            False)
  --no-cell-borders         Suppress internal Markdown table cell borders and
                            leave whitespace gaps between cells. (default:
                            False)
  --automation-timeout SECONDS
                            Inject synthetic quit after the given viewer
                            runtime for automation runs. (default: None)
  --automation-timeout-screenshot BASENAME
                            Write timeout-exit framebuffer artifacts using
                            BASENAME, producing BASENAME.txt and
                            BASENAME.attrs.json. Defaults to ./mdview-
                            automation-timeout-framebuffer when --automation-
                            timeout is set. (default: None)
  --screen-dump-dir DIRECTORY
                            Directory for manual ! framebuffer captures in the
                            interactive pager. Defaults to the current working
                            directory. (default: .)
  --viewport-columns COLUMNS
                            Override detected viewport width with a synthetic
                            value. (default: None)
  --viewport-rows ROWS      Override detected viewport height with a synthetic
                            value. (default: None)
  --allow-insane-geometry   Render viewport geometry above 512 cells per axis.
                            Without this flag, values up to 16384 are accepted
                            but only the first 512 cells per axis are
                            rendered. With this flag, the absolute limit is
                            65535 cells per axis. (default: False)
  --automation-json SOURCE  Replay key events from JSON SOURCE (file path or
                            literal JSON string) as [[delay_seconds,
                            key_spec], ...]. (default: None)
  --allow-huge-automation-scripts
                            Allow automation JSON sources up to 4 GiB instead
                            of the default 16 MiB ceiling. (default: False)
  --redraw-check-digit      Overlay a center-screen digit that advances from 0
                            to 9 on each interactive pager redraw. (default:
                            False)
  -V, --version             Show the mdview version and exit.
