usage: mdview [-h] [--pager COMMAND] [-V] path

Render Markdown in the terminal with less-like navigation.

positional arguments:
  path             Path to a Markdown or text file to view.

options:
  -h, --help       show this help message and exit
  --pager COMMAND  Optional pager command to override the default less/pydoc
                   pager (e.g., 'less -R'). (default: None)
  -V, --version    Show the mdview version and exit.
