Running Tests
============

Prerequisites
-------------
- Python 3.9 or newer available on your PATH.
- Run `./scripts/install_prerequisites.sh` from the repository root before
  first use in a fresh checkout or environment.
- The installer provisions `.venv/` in the checkout, installs required system
  tools when available, and installs the project with development extras in
  an isolated environment.
- After bootstrap, run commands with `.venv/bin/python` or activate `.venv`
  before using `python`.

Standard test run
-----------------
- Execute the full suite from the repository root:
  - `.venv/bin/python scripts/run_tool_with_timeout.py pytest`
- For sanity checks before commits, also run:
  - `.venv/bin/python scripts/run_tool_with_timeout.py black`
  - `.venv/bin/python scripts/run_tool_with_timeout.py ruff`
  - `.venv/bin/python scripts/run_tool_with_timeout.py compileall`

Focused execution
-----------------
- To target specific tests while iterating, use `-k` to match a substring:
  - `.venv/bin/python scripts/run_tool_with_timeout.py pytest -- -k`
    `plain_text`
- To rerun a single file or test function:
  - `.venv/bin/python scripts/run_tool_with_timeout.py pytest --`
    `tests/test_rendering.py::`
    `test_render_to_ansi_preserves_five_line_plain_text`

Environment Notes
-----------------
- Tests rely on static fixtures stored under `resources/tests/`. Keep these
  files in sync with their user stories.
- Use UTF-8 when reading fixture files to preserve ASCII compatibility
  guarantees.
- Tool timeouts are configured in `scripts/tool_timeouts.json`. Keep defaults
  short. Increase a timeout only when a shorter value is confirmed to
  interrupt a legitimate run.
- For one-off overrides, pass `--timeout-seconds`, for example:
  `.venv/bin/python scripts/run_tool_with_timeout.py pytest
  --timeout-seconds 300 -- -k nested`
- If `.venv/bin/python` cannot import `black`, `ruff`, or `pytest`, stop and
  repair the local bootstrap before trusting any test result.
