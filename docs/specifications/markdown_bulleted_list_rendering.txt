Markdown Bulleted List Rendering Specification
=============================================

Scope
-----
Define how mdview renders Markdown bulleted lists so hyphen and asterisk
markers remain visible, spacing stays predictable, and items do not merge. Set
fixtures that isolate single-level lists while leaving nested list behavior to
a separate specification.

Assumptions
-----------
- Rendering prefers ``rich.markdown.Markdown`` and falls back to a plain-text
  formatter when Rich is unavailable.
- Inputs preserve author spacing; renderers must not reorder or collapse list
  items.
- Fixtures live under ``resources/tests/markdown/lists`` and avoid mixing list
  markers with ordered lists or nested structures.
- Assertions focus on list cues such as prefixes, indentation, and separation
  instead of brittle full-output snapshots.

Rendering Rules
---------------
- Recognize list items that start with ``- `` or ``* ``. Preserve all text on
  the same line after the marker without trimming interior spacing.
- Emit consistent indentation so bullet markers align vertically within the
  same list. In fallback mode, surface literal ``-`` and ``*`` prefixes.
- Keep each list item on its own rendered line. Do not concatenate bullet text
  with adjacent items or surrounding paragraphs.
- Allow inline emphasis inside list items while preventing styling from
  leaking into markers or neighboring lines.

Spacing and Separation Expectations
-----------------------------------
- Maintain a blank line between surrounding prose and the first or last list
  item so lists remain visually distinct.
- Preserve single blank lines between bullet items when present in the source;
  treat double blanks as intentional breaks rather than collapsing them.
- Avoid merging adjacent hyphen and asterisk lists. A change in marker type
  starts a new list block even without an intervening blank line.

Fixture Inventory
-----------------
- ``resources/tests/markdown/lists/bulleted_hyphen.md``: Hyphen-prefixed list
  with leading and trailing prose. Confirms alignment, separation from prose,
  and literal markers in fallback mode.
- ``resources/tests/markdown/lists/bulleted_asterisk.md``: Asterisk-prefixed
  list mirroring the hyphen fixture to verify consistent spacing and prefix
  cues.
- ``resources/tests/markdown/lists/bulleted_mixed_markers.md``: Adjacent
  hyphen and asterisk lists without intervening blank lines. Ensures renderers
  start a new block when the marker changes.
- ``resources/tests/markdown/lists/bulleted_spacing.md``: Items separated by
  intentional blank lines and inline emphasis. Validates spacing preservation
  and containment of emphasis styling inside each item.

Exit Criteria
-------------
- All fixtures above exist under ``resources/tests/markdown/lists`` with
  content that reflects the rendering and spacing rules.
- Renderers display aligned bullet markers and preserve spacing across Rich
  and fallback modes.
- Hyphen and asterisk lists remain separated when marker types change, and
  item text stays confined to its own line with contained emphasis styling.
