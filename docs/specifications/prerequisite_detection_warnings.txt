Title: Prerequisite detection warnings
Date: 2025-02-13
Author: R. Talon

Goal
- Detect when mdview is missing runtime prerequisites that the install
  scripts normally provide and inform the operator immediately.

Background
- Operators sometimes skip scripts/install-prerequisites, leaving optional
  dependencies such as rich or prompt_toolkit uninstalled.
- When that happens the mdview shim may execute but produce no visible
  output, leaving the user without guidance.

Requirements
- Before argument parsing, mdview must check for missing optional
  dependencies (rich, prompt_toolkit) and the default pager command less.
- When any prerequisite is missing, mdview must print a short, actionable
  warning to stderr, suggesting running scripts/install-prerequisites or
  installing the named tool.
- The warnings must appear even when the process exits early due to
  --help or argument parsing errors.
- Add unit coverage that simulates missing prerequisites and asserts the
  emitted warnings.

Non-Goals
- Do not change fallback rendering behavior beyond the new warnings.
