Support Package Currency
========================

Scope
-----
Keep mdview's supporting package declarations current when an operator
requests a package refresh.

Requirements
------------
- Update pinned development support packages in `requirements-dev.txt` to the
  latest compatible releases available from the package index.
- Pin mdview runtime, interactive, and development support dependencies in
  `pyproject.toml` to the same validated versions used by the active
  repository `.venv`.
- Upgrade `pip`, `setuptools`, and `wheel` inside the repository `.venv` so
  the active development environment uses current packaging tools.
- Preserve Python 3.9+ compatibility in bootstrap and installer code, and
  preserve Python 3.12 as the steady-state local tool runtime.
- Do not update Codex packages in `package.json`, `package-lock.json`,
  ignored `.codex-local/` state, or other `.local/` operator state. Codex
  package currency is owned by codex-wrangler, not this repository task.
- Regenerate tracked package metadata when package updates change it.

Validation
----------
- Run the standard local checks through `scripts/run_tool_with_timeout.py`:
  `black`, `ruff`, `compileall`, `entropy_check`,
  `entropy_tripwire_verify`, `pytest`, and `demo_check`.
- Report local Windows shim validation separately when the current host lacks
  usable Wine or rootless Podman support.
